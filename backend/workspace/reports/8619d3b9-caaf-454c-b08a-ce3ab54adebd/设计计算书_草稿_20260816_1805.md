## 3 键连接

### calc#4 平键工作长度反解与标准键长选取

依据：机械设计（第十版）式 6-1 反解键长；GB/T 1096-2003 键长标准系列

公式：`（沙箱脚本，见 script 字段）`

输入：T_Nm = 420 N*m，d = 60 mm，h = 11 mm，b = 18 mm，sigma_pP = 120 MPa

代入：T_Nm=420 N*m；d=60 mm；h=11 mm；b=18 mm；sigma_pP=120 MPa

结果：l_req = 21.21 mm，L_req = 39.21 mm，L_sel = 50 mm，l_work = 32 mm

计算脚本：

```python
T = T_Nm * 1000.0
l_req = 4 * T / (d * h * sigma_pP)
L_req = l_req + b
length_series = [10, 12, 14, 16, 18, 20, 22, 25, 28, 32, 36, 40, 45, 50, 56, 63, 70, 80, 90, 100, 110, 125, 140, 160, 180, 200]
l_min = 50
target = max(L_req, l_min)
L_sel = None
for x in length_series:
    if x >= target:
        L_sel = x
        break
l_work = L_sel - b
outputs['l_req'] = l_req
outputs['L_req'] = L_req
outputs['L_sel'] = L_sel
outputs['l_work'] = l_work
```

### calc#10 齿轮位键槽削弱后的抗弯截面系数

依据：机械设计（第十版）表 15-4 实心轴抗弯截面系数；单键槽按 bt(d-t)²/(2d) 折减

公式：`（沙箱脚本，见 script 字段）`

输入：d = 60 mm，b = 18 mm，t = 7 mm

代入：d=60 mm；b=18 mm；t=7 mm

结果：W_solid = 2.121e+04 mm**3，W_net = 1.826e+04 mm**3

计算脚本：

```python
W_solid = math.pi * d**3 / 32.0
W_keyway = b * t * (d - t)**2 / (2.0 * d)
W_net = W_solid - W_keyway
outputs['W_solid'] = W_solid
outputs['W_net'] = W_net
```
