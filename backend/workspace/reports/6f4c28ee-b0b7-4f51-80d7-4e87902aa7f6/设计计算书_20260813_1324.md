### calc#1 碰撞等效静载推算——能量法

依据：动能-变形能守恒原理。线性弹性假设：F_max = 2E_k/δ；塑性平台假设：F_avg = E_k/δ

公式：`（沙箱脚本，见 script 字段）`

输入：m = 2000 kg，v = 3.6 m/s，delta_max = 0.1 m

代入：m=2000 kg；v=3.6 m/s；delta_max=0.1 m

结果：E_k_J = 1.296e+04 J，F_max_linear_kN = 259.2 kN，F_avg_plastic_kN = 129.6 kN，v_kmh = 12.96

计算脚本：

```python
# 碰撞条件
m = 2000.0      # kg
v = 3.6         # m/s
delta_max = 0.100  # m, 允许变形量

# 动能 E_k = 0.5 * m * v^2
E_k = 0.5 * m * v**2

# 能量法：假设载荷从0线性增加到F_max，变形能 = 0.5 * F_max * delta_max = E_k
# 则 F_max = 2 * E_k / delta_max
F_max = 2 * E_k / delta_max

# 若假设塑性平台（恒力F_avg）：F_avg * delta_max = E_k
F_avg = E_k / delta_max

outputs = {
    'E_k_J': E_k,
    'F_max_linear_kN': F_max / 1000.0,
    'F_avg_plastic_kN': F_avg / 1000.0,
    'v_kmh': v * 3.6
}
```

    (180, 120, 8),

    (180, 130, 10),
    (180, 150, 8),
    (180, 150, 10),
    (200, 100, 8),
    (200, 100, 10),
    (200, 120, 8),

    (200, 130, 8),
    (200, 130, 10),
    (200, 150, 8),

### calc#7 矩形管 200×130×8 补充校核：剪切应力、局部屈曲、支座挤压

依据：材料力学（剪切应力τ=VQ/(Ib)）；GB 50017-2017 钢结构设计标准（宽厚比限值）；机械设计手册（挤压应力）

公式：`（沙箱脚本，见 script 字段）`

输入：H = 200 mm，B = 130 mm，t = 8 mm，F = 130 kN

代入：H=200 mm；B=130 mm；t=8 mm；F=130 kN

结果：tau_max_MPa = 24.76，tau_allow_MPa = 102.4，tau_margin_pct = 313.6，flange_ratio = 14.2，flange_limit = 32.5，web_ratio = 23，web_limit = 57，sigma_bearing_MPa = 5，sigma_bearing_allow_MPa = 177.5，bearing_margin_pct = 3450

判据：τ_max ≤ τ_allow = 0.577σ_s/n_s；翼缘b/t≤40ε，腹板h/t≤70ε（S4截面）；σ_bearing ≤ σ_s/n_s → —

计算脚本：

```python
# ============================================================
# 截面：200×130×8 矩形空心型钢（45钢调质）
# 载荷：F=130kN 跨中集中，支点反力 R=65kN
# ============================================================

H = 200.0  # mm 截面高度
B = 130.0  # mm 截面宽度
t = 8.0    # mm 壁厚
F = 130e3  # N 载荷
L = 1400.0 # mm 支点间距
R = F / 2  # N 每支座反力

# ---------- 1. 剪切应力校核 ----------
# 矩形空心截面 max shear at NA: τ = V*Q/(I*b)
I = 2749e4  # mm^4 (2749 cm^4)

# Q = 中性轴以上面积对中性轴的一次矩
# 外矩形上半部分对NA的静矩
Q_outer = B * (H/2) * (H/4)
# 内空腔上半部分：从 y=t 到 y=H/2
# 内空腔半高 = H/2 - t，其形心距NA = t + (H/2 - t)/2 = H/4 + t/2
# 距离NA = H/2 - (H/4 + t/2) = H/4 - t/2
Q_inner = (B - 2*t) * (H/2 - t) * (H/4 - t/2)
Q_net = Q_outer - Q_inner

b_web = 2 * t  # 两个腹板总厚度

tau_max = R * Q_net / (I * b_web)  # MPa

sigma_s = 355.0  # MPa 45钢调质屈服
tau_s = 0.577 * sigma_s
n_s = 2.0
tau_allow = tau_s / n_s
tau_margin = (tau_allow / tau_max - 1) * 100
tau_pass = tau_max <= tau_allow

# ---------- 2. 局部屈曲校核（宽厚比限值）----------
flange_ratio = (B - 2*t) / t
web_ratio = (H - 2*t) / t

fy = sigma_s
eps = (235 / fy)**0.5
flange_limit = 40 * eps
web_limit = 70 * eps

flange_pass = flange_ratio <= flange_limit
web_pass = web_ratio <= web_limit

# ---------- 3. 支座挤压应力 ----------
support_width = 100.0  # mm
bearing_area = B * support_width  # mm^2
sigma_bearing = R / bearing_area  # MPa
sigma_bearing_allow = sigma_s / n_s
bearing_margin = (sigma_bearing_allow / sigma_bearing - 1) * 100
bearing_pass = sigma_bearing <= sigma_bearing_allow

# ---------- 输出 ----------
outputs['tau_max_MPa'] = round(tau_max, 2)
outputs['tau_allow_MPa'] = round(tau_allow, 1)
outputs['tau_margin_pct'] = round(tau_margin, 1)
outputs['tau_pass'] = tau_pass
outputs['flange_ratio'] = round(flange_ratio, 1)
outputs['flange_limit'] = round(flange_limit, 1)
outputs['flange_pass'] = flange_pass
outputs['web_ratio'] = round(web_ratio, 1)
outputs['web_limit'] = round(web_limit, 1)
outputs['web_pass'] = web_pass
outputs['sigma_bearing_MPa'] = round(sigma_bearing, 2)
outputs['sigma_bearing_allow_MPa'] = round(sigma_bearing_allow, 1)
outputs['bearing_margin_pct'] = round(bearing_margin, 1)
outputs['bearing_pass'] = bearing_pass
```
