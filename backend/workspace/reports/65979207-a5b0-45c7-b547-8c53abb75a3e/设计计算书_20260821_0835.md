### calc#15 齿轮啮合受力（圆周力/径向力）

依据：机械设计（第十版）：Ft=2T/d，Fr=Ft·tan20°（标准直齿圆柱齿轮，压力角 20°）

公式：`（沙箱脚本，见 script 字段）`

输入：T1 = 2.653e+04 N*mm，T2 = 1.009e+05 N*mm，d1 = 48 mm，d2 = 192 mm

代入：T1=2.653e+04 N*mm；T2=1.009e+05 N*mm；d1=48 mm；d2=192 mm

结果：Ft1 = 1105 N，Fr1 = 402.3 N，Ft2 = 1051 N，Fr2 = 382.5 N

计算脚本：

```python
alpha = math.radians(20)
Ft1 = 2 * T1 / d1
Fr1 = Ft1 * math.tan(alpha)
Ft2 = 2 * T2 / d2
Fr2 = Ft2 * math.tan(alpha)
outputs['Ft1'] = Ft1
outputs['Fr1'] = Fr1
outputs['Ft2'] = Ft2
outputs['Fr2'] = Fr2
```
